# Pitayas Media

Pobieranie filmów i muzyki na komputerze: YouTube i ~1800 stron (yt-dlp), zwykłe linki (także ⚡ debrid z Pitaya Streams) i torrenty. Moduł **Pitayas Media** w aplikacji Pitayas na telefonie zleca pobieranie przez sieć lokalną (port 8193), a gotowy plik przechodzi na telefon.

- yt-dlp pobiera się sam przy pierwszym użyciu, ffmpeg jest w paczce.
- Pliki: `~/Pobrane/Pitayas Media` (do zmiany w ustawieniach).

```bash
npm install
npm start
```
